    Filters for every folder of a type

    Regular expressions, case-insensitive, matched against folder names or file names. They add to each folder’s own filters. Games are never filtered: a game folder always syncs complete.

    SETTINGS

    Settings.

    Saved data

    Settings, reports and sync logs are stored in .

    Artwork and metadata

    Without an account, ROMs get covers, screenshots and basic details from libretro and PC games from Steam. A ScreenScraper account (optional) adds descriptions and better matches for ROMs. ScreenScraper also requires developer credentials, which you request on screenscraper.fr; scraping then goes one request at a time within its limits.

    Running in the background

    Closing the window keeps Odin Sync running in the tray, so your devices can find this PC and sync. Quit it from the tray icon's menu.

    Web server and PIN

    Odin Sync runs a small web server on the local network for the Odin Sync app and for browsers (for example the Odin's own browser). Browsers sign in with your PIN; while a browser is in control, this window is paused until you take control back.

    Reset all settings

    Clears local folders, filters, devices, profiles and the library cache. A backup of the current settings is written first. Files on this PC and on your devices are never touched. Devices need to be paired with the Odin Sync app again afterwards.
